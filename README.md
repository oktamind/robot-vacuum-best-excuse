One line, in the robot vacuum's own deadpan voice, explaining why it missed a spot: its cliff sensor mistook the dark rug for a cliff, so it left the crumbs there — and the crumbs now have squatter's rights. A real sensor failure mode, with the joke turning on the last four words.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the excuse (110 characters, one line) to `out/entry.txt`.
